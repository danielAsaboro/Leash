## Negative results that shaped the system

| Finding | Design consequence |
| --- | --- |
| Qwen3 4B dropped dependent next calls even when a continuation nudge was injected. | Step-declared skills use deterministic harness pipelines. |
| Dynamic tool compaction was enabled at model load, so a tool-less request could fail. | The QVAC fork now sets `tools_compact` per request only when a dynamic request actually carries tools. |
| A tools-disabled chat serve makes the model talk about tools instead of calling them. | Dashboard-added chat aliases default to `tools:true, toolsMode:"dynamic"`. |
| Full-agent routing made simple tool turns slow. | Narrow deterministic paths now run registered tools and broker actions before a model decode. |
| The planned Layer-1 reconnection monkey-patch could not reach the SDK Bare worker. | The overbuilt resilience layer was killed; the real fix was distinct DHT seeds. |
| An early 600M memory-evolution run scored 0% recall at 2 epochs. | Training moved to the trainable 8B base, frozen evaluation remained unchanged, and the current adapter now has two positive held-out comparisons. |
| The evaluation command selected a 600M default for an 8B adapter and crashed the native worker. | Evaluation resolves and validates the adapter's original base before model load; mismatches fail without applying the adapter. |
| Hermes failed on modern SDK polyfill syntax. | iOS uses JavaScriptCore. |
| QVAC 0.13.x does not expose speculative decoding through its config schema or public addon interface. | No unsupported draft-model config is shipped or claimed. |
| QVAC could still emit a domain tool call when `toolChoice: none` was sent with that tool schema. | Prose-only pipeline steps no longer receive the domain schema; only the authored deterministic step can see it. |
| A fragment such as “he's sweaty now too” did not independently score the triage skill. | Carry the prior persisted skill only for bounded dependent fragments, and release it on explicit topic changes. The uninterrupted 16-turn run passes both continuity and off-domain release. |

See [Real-user capability gauntlet](/optimization/capability-gauntlet) for the prompts, failures, fixes, and acceptance contract.
